xapiweb

A zero-dependency Python client for selected X web API operations, with structured responses, pacing, transaction IDs, write verification, and resource modules.

Python 3.8+No runtime dependenciesUnofficial client

Install

pip install xapiweb

For a local editable checkout, run pip install -e .. The package is designed for Python 3.8 and newer.

Quick start

from xapiweb import XClient
from xapiweb.resources.timelines import extract_tweets

x = XClient.from_session_file("my_data.json")
print(x.health().status)
print(x.me())

for tweet in extract_tweets(x.timelines.home(count=10)):
    print(tweet["author"], tweet["text"][:80])
Keep sessions private. A session file can contain a live browser session. Never commit my_data.json, cookies, CSRF tokens, bearer tokens, or generated caches to GitHub, PyPI, screenshots, or issue trackers.

Authentication

Sign in to X in a desktop browser. From a request in browser developer tools, copy the complete Cookie header and the x-csrf-token header. The CSRF value must match the ct0 cookie value.

from xapiweb import XClient

x = XClient(cookie="<full-cookie>", csrf_token="<ct0-value>")
print(x.health().status)  # 200 means connected

For the complete Sinhala walkthrough, read CONNECT_GUIDE.md.

Capabilities

ReadsTimelines, search, trends, users, notifications, lists, communities, settings, tweet details, media, and statistics.
WritesTweets, replies, threads, polls, deletes, pins, disclosures, follows, moderation, likes, reposts, bookmarks, and selected DMs.
MediaImage upload, chunked video upload, media inspection, and downloads.
ReliabilityRequest pacing, limited retry handling, transaction ID management, structured errors, and verification of state-changing operations.

Responses and errors

Each request returns a Response object with status, data, raw, ok, get(), and summary().

Important exception types include XAuthError, XRateLimitError, XTxnError, XValidationError, XApiError, and XVerifyError. A successful HTTP acknowledgement is not treated as proof that a state change completed; verification is enabled by default.

Tests and responsible use

python3 xapiweb/tests/test_offline.py

The offline test suite does not contact X. Live smoke and quickstart scripts require your own private session. Use a conservative request pace, respect X terms and rate limits, and operate only on accounts and data you are authorized to control. Operations with real-world side effects require explicit confirmation where applicable.
